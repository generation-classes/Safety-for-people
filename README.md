# Safety for People (SAPE)
##  Deploy 
https://generation-classes.github.io/Safety-for-people/pages/home-usuario/index.html

Marketplace web de dispositivos de seguridad para familias. Proyecto frontend con HTML, CSS, Bootstrap y JavaScript.

## Estructura

- `index.html` — Inicio
- `pages/` — About us, productos, contacto
- `components/` — Navbar y footer
- `Assets/images/` — Imágenes y logos
- `styles.css` / `script.js` — Estilos y lógica

## Cómo verlo

Abre `index.html` con Live Server (recomendado) o en el navegador.
